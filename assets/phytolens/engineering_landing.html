The Challenge

01 THE PROBLEM

Delayed Diagnosis & Connectivity

Farmers in remote areas often struggle with internet connectivity. Cloud-only AI solutions fail when they are needed most—in the field. Additionally, accessing expert advice is expensive and slow, leading to crop loss before a solution is found.

02 THE SOLUTION

Edge AI & Offline Sync

PhytoLens moves the "Brain" to the device. By quantizing a MobileNetV2 model to TFLite, we enable 14ms inference time completely offline. A local SQLite database provides instant treatment plans, syncing with the cloud only when connectivity is restored.

Tech Stack

Modern technologies powering a scalable, distributed offline-first system.

Flutter

Mobile Client

Single codebase for high-performance native compilation on Android and iOS with 60fps UI.

TensorFlow Lite

On-Device AI

Quantized MobileNetV2 achieving 98% accuracy with 14ms inference on low-end devices.

FastAPI

Backend API

Async Python server handling JWT authentication, user data, and weather syncing with <50ms response.

PostgreSQL

Cloud Database

Relational database storing user profiles, scan history, and analytics with JSONB support.

Docker

DevOps

Containerization ensuring consistent environments from local development to cloud production.

SQLite

Local Storage

Embedded database storing 38 disease classes, 400+ treatment plans, and offline scan history.
